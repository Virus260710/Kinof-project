# User Flows — Smart Lab (อัปเดตล่าสุด)

> Auth แบบ Adaptive: [AUTH_ADAPTIVE.md](./AUTH_ADAPTIVE.md)  
> **สแกนผ่าน → เข้าได้เลย | ไม่ผ่าน → OTP จากเว็บที่ Kiosk**

---

## การถ่ายใบหน้า — เปิดกล้อง ระบบจับภาพเอง

```
User กด "ลงทะเบียนใบหน้า" / "ลงทะเบียน"
    ↓
เปิดกล้อง (Camera Modal) → ระบบจับภาพอัตโนมัติเมื่อใบหน้าชัด
    ↓
Face Service → embedding → เก็บ DB
```

---

## เข้าห้องที่ Kiosk (ทุกกลุ่ม)

```
1. สแกนใบหน้า
   ├─ ผ่าน → ตรวจสิทธิ์ → ได้ที่นั่ง ✅
   └─ ไม่ผ่าน → กรอก OTP ที่ขอจากเว็บ → ตรวจสิทธิ์ → ได้ที่นั่ง ✅
2. Agent บันทึก log
```

## Login เว็บ (OTP ทาง Email)

```
1. กรอก user/pass → ระบบส่ง OTP ไป email
2. กรอก OTP ที่ /login/otp → เข้า Dashboard
3. (เผื่อ Kiosk) กด "ขอรหัสเข้าห้อง" → OTP ส่ง email → กรอกที่ Kiosk ถ้าสแกนไม่ผ่าน
```

---

## กลุ่ม 1: นักศึกษามีตารางเรียน

```
[ครั้งแรก] Kiosk → ลงทะเบียนใบหน้า (auto-capture)

[ทุกครั้ง]
1. มาหน้าห้อง Lab (ช่วงมีคาบ)
2. สแกนหน้า → ผ่าน → ตรวจตารางเรียน → ได้ที่นั่ง
   (ไม่ผ่าน → OTP จากเว็บ)
3. Agent log
```
**ไม่ต้องจองล่วงหน้า**

---

## กลุ่ม 2: นักศึกษาไม่มีตารางเรียน

```
1. Login เว็บ → จอง (ห้อง/วัน/เวลา) → (optional) ขอ OTP สำรอง
2. มาหน้าห้อง → สแกนหน้า (หรือ OTP) → ตรวจ booking → ได้ที่นั่ง
3. Agent log
```

---

## กลุ่ม 3: บุคคลภายนอก

```
1. ลงทะเบียนเว็บ → กรอกข้อมูล → กล้อง auto-capture → ใช้ได้ทันที
2. Login → จอง (ห้อง/วัน/เวลา) → (optional) ขอ OTP สำรอง
3. มาหน้าห้อง → สแกนหน้า (หรือ OTP) → ตรวจ booking → ได้ที่นั่ง
4. Agent log
```

---

## เปรียบเทียบ

| | กลุ่ม 1 | กลุ่ม 2 | กลุ่ม 3 |
|---|---------|---------|---------|
| จองล่วงหน้า | ไม่ | เว็บ | เว็บ |
| เข้าห้อง | Scan → เข้า (OTP สำรอง) | Scan/OTP | Scan/OTP |
| ตรวจสิทธิ์ | Schedule | Booking | Booking |
