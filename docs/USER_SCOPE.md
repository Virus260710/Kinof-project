# ขอบเขตด้านผู้ใช้งาน — Smart Lab

> Flow ละเอียด: [FLOWS.md](./FLOWS.md)

## การถ่ายใบหน้า — เปิดกล้อง ระบบจับภาพเอง

**ไม่อัปโหลดไฟล์** — เปิด Camera Modal → ระบบตรวจ real-time → **auto-capture** เมื่อใบหน้าชัด

---

## กลุ่ม 1: นักศึกษามีตารางเรียน

1. (ครั้งแรก) Kiosk → ลงทะเบียนใบหน้า (กล้อง auto-capture)
2. มาหน้าห้อง → สแกนหน้า + 2FA
3. ตรวจตารางเรียนอัตโนมัติ → ได้ที่นั่ง → Agent log

**ไม่ต้องจองล่วงหน้า**

---

## กลุ่ม 2: นักศึกษาไม่มีตารางเรียน

1. Login เว็บ → **จอง** (ห้อง / วัน / เวลา)
2. มาหน้าห้องตามเวลา → สแกนหน้า + 2FA
3. ตรวจ booking → ได้ที่นั่ง → Agent log

---

## กลุ่ม 3: บุคคลภายนอก

1. ลงทะเบียนเว็บ → กรอกข้อมูล → **กล้อง auto-capture** → **ใช้ได้ทันที**
2. Login → **จอง** (ห้อง / วัน / เวลา)
3. มาหน้าห้อง → สแกนหน้า + 2FA → ตรวจ booking → Agent log

---

## ตารางเปรียบเทียบ

| | มีตารางเรียน | ไม่มีตารางเรียน | บุคคลภายนอก |
|---|:---:|:---:|:---:|
| จองล่วงหน้า | ไม่ | ใช่ (เว็บ) | ใช่ (เว็บ) |
| ลงทะเบียนใบหน้า | Kiosk auto-capture | Kiosk (ถ้ายังไม่มี) | เว็บ auto-capture |
| Admin approve | - | - | **ไม่ต้อง** |
| เข้าห้อง | Face (+ OTP email สำรอง) | Face (+ OTP email) | Face (+ OTP email) |
| ตรวจสิทธิ์จาก | Schedule | Booking | Booking |
